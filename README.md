# Брецель — немецкий с нуля

Мобильный сайт-курс (PWA) по немецкому языку: с нуля до A2 по программе Goethe-Zertifikat. Объяснения на русском, уроки по 5 минут, игры, интервальное повторение и тетрадь ошибок. План курса и статус блоков — в [COURSE_PLAN.md](COURSE_PLAN.md).

## Запуск

```bash
python scripts/serve.py
```

Откройте http://localhost:5173.

## На телефоне

Курс опубликован на GitHub Pages: **https://bahhtee17.github.io/brezel/**

Откройте ссылку на телефоне и установите как приложение:

- **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** меню ⋮ → «Установить приложение» или «Добавить на главный экран».

После первого открытия уроки работают и без интернета. Прогресс хранится в браузере телефона: если очистить данные Safari/Chrome или удалить приложение, он сбросится.

Обновление сайта: закоммитьте изменения и выполните `git push` — GitHub Pages пересоберёт сайт за 1–2 минуты. Не забудьте увеличить `VERSION` в `sw.js`, иначе телефон может показать старую версию из кэша.

## Озвучка

Все фразы курса озвучены живыми голосами (`audio/manifest.json`: текст → mp3). Фразы без записи читает голос браузера (Web Speech API); лучше всего звучат Chrome и Edge.

**Бесплатно, на своём компьютере — VoiceStudio.** Откройте VoiceStudio (сервер на `http://localhost:3900`) и запустите:

```bash
node scripts/generate-audio-local.mjs
```

Скрипт озвучивает только фразы, которых ещё нет в `audio/manifest.json`, обрезает тишину, выравнивает громкость под остальные записи и пишет mp3 44,1 кГц 64 кбит/с. Голос каждого героя задан образцом `scripts/voice-refs/<герой>.wav`; описание голосов — в `scripts/voices-local.json`, пересоздать образец: `node scripts/generate-audio-local.mjs --design lena`. Модель OmniVoice распространяется по лицензии CC BY-NC: эти записи можно использовать только в некоммерческом курсе, автора модели (k2-fsa) нужно указывать.

**Платно — ElevenLabs:**

```bash
node scripts/generate-audio.mjs --dry-run
```

Команда считает фразы и символы и пишет список в `audio/TODO.md`. Для генерации задайте переменную окружения `ELEVENLABS_API_KEY`, затем:

```bash
node scripts/generate-audio.mjs --pick-voices
node scripts/generate-audio.mjs
```

**Без ключа — через плагин ElevenLabs в Claude.** `node scripts/audio-chunks.mjs` делит фразы на пачки по 8 штук, каждая фраза с новой строки (`audio/chunks.json`). Плагин озвучивает пачку (модель `eleven_multilingual_v2`), а Scribe расшифровывает её с временем каждого слова. Записи и разметку нужно положить в `audio/raw/<пачка>.mp3` и `<пачка>.words.json`, после чего `python scripts/audio-align.py` режет запись точно по словам. Теги пауз `<break>` не использовать: при нескольких паузах модель ускоряет речь в 2–2,5 раза.

Первая команда подбирает героям голоса из вашего аккаунта ElevenLabs (по полу, возрасту и немецкому языку) и записывает их в `scripts/voices.json`; любой голос можно заменить вручную. Вторая озвучивает только новые фразы (mp3, 64 кбит/с). Ключ не сохраняется в файлах проекта. После генерации увеличьте `VERSION` в `sw.js`.

## Иллюстрации и анимации

Стиль: рисованный мультфильм — толстый «фломастерный» контур, текстура масляной пастели, огромные круглые глаза, плоский цветной фон. Картинки рисует Codex (генерация изображений), анимации собирает Remotion.

1. `python scripts/art-prompts.py` — пишет `art/assets.json`: общий стиль, описания героев и промпт для каждой картинки.
2. Codex рисует по инструкции `art/CODEX.md` и сохраняет PNG в `art/raw/` (эта папка не коммитится).
3. `python scripts/process-art.py` — делает лёгкие WebP в `img/` (у маскота вырезает фон) и список `img/index.json`.
4. Анимации глаголов: Codex рисует вторую позу (`art/raw/anim/<слово>-b.png`), затем `cd anim && npm install && npm run render` — Remotion собирает зацикленные mp4 в `img/anim/` (позы сменяются, линия «дрожит», как в рисованном мультфильме). После этого снова `python scripts/process-art.py`.

Если картинки для слова нет, сайт рисует запасную SVG-иллюстрацию из `js/art.js`.

## Видео-объяснения

Короткие вертикальные ролики (9:16, 1–2 минуты), как у Khan Academy, но по-русски: объясняет учитель Брецель. Один шаблон на все ролики, поэтому стиль везде одинаковый: кремовая «бумага», шрифт Nunito, цвета приложения, учитель внизу слева, субтитры внизу, одни и те же переходы.

Сейчас готовы сценарии 6 глав «Чтения» (`read-*`) и 12 уроков блока 1 (`a1-01-01` … `a1-01-12`).

1. **Сценарий** — `video/scripts/<id>.json` (формат описан в поле `_format` пилота `read-vowels.json`). Сцены собираются из 17 готовых блоков:
   - чтение: `title`, `image`, `rule`, `word`, `quiz`, `phrase`, `mnemonic`, `compare`, `tip`, `recap`, `outro`;
   - уроки: `list` (до 5 слов с картинками или флагами), `dialog` (диалог урока с аватарами), `table` (спряжение; `wohn{e}` подсвечивает окончание), `order` (порядок слов, `*` — глагол), `form` (анкета), `ask` («ваша очередь»: вопрос, пауза, ответ).

   Пункт появляется на реплике с номером `at` (счёт с нуля по массиву `say`). Реплики учителя — только кириллицей (немецкие буквы — «э-и», «а-у»); немецкие слова и фразы звучат записями курса (`{ "de": "nein" }`, текст должен быть ключом `audio/manifest.json`). Очень короткие реплики модель озвучивает тишиной — пишите полными предложениями. Урок по схеме: заставка → сцена из истории → слова и правило → диалог → «ваша очередь» → «Начать урок».
2. **Рисунки** — в стиле курса через Codex: промпт в `scripts/art-prompts.py` (группа `video`), затем `python scripts/art-prompts.py` и задание Codex по `art/CODEX.md`. Картинки слов берутся из `art/raw/words`.
3. **Сборка** — откройте VoiceStudio, затем `cd anim && node render-video.mjs <id>`. Скрипт озвучивает реплики голосом учителя (`scripts/voice-refs/teacher-ru.wav`, настройки — `teacherRu` в `scripts/voices-local.json`), считает таймлайн по длине реплик, вырезает фон рисунков и рендерит `video/<id>.mp4` (720×1280) и обложку `video/<id>.jpg`. Готовые реплики кэшируются: правка одной не переозвучивает остальные. `--check` — проверка сценариев, `--audio` — только озвучка, `--stills` — по кадру из каждой сцены для проверки вёрстки (лист `video/.cache/stills/<id>.jpg`), `--draft` вместе с `--stills` — то же без VoiceStudio (длительность реплик оценивается по тексту). `all --missing` — отрендерить всё, чего ещё нет. Перед долгим рендером закройте VoiceStudio: модель занимает около 7 ГБ памяти.
4. **В приложении** — поле `video` (`src`, `poster`, `len`) у главы в `content/reading.json` или у урока в файле темы (`content/a1/01-hallo.json`); карточка «Видео-объяснение» появляется на странице правила и на первом экране урока (`js/video.js`). Видео не кэшируется для офлайна: грузится по нажатию.

### Живой маскот

Стартовые кадры рисует Codex (группа `moves` в `scripts/art-prompts.py`, пурпурный фон), движение делает Grok Imagine (ролик 6 с кладётся в `art/raw/grok/<имя>.mp4`). `python scripts/mascot-moves.py [имена]` убирает фон и собирает анимированные WebP в `img/moves/`. Где какая анимация играет — `COMBO_MOVE` и итоговые экраны в `js/player.js`, главная — `js/screens.js`.

Шаблон — `anim/src/video/`: `Explainer.jsx` (каркас: бумага, учитель, субтитры, полоса прогресса), `scenes-a.jsx` и `scenes-b.jsx` (сцены), `kit.jsx` (палитра, шрифт, подгонка размеров). Голос OmniVoice — лицензия CC BY-NC, только для бесплатного курса.

## Новый блок

Добавьте файл темы в `content/`, отметьте тему `"ready": true` в `content/course.json`, добавьте файл в список `SHELL` в `sw.js` и увеличьте там `VERSION`.

## Языки объяснений: русский и узбекский

Язык выбирается на первом экране и в профиле (Настройки → Язык объяснений). Немецкая часть уроков общая.

- Русский текст в коде и в уроках — основной, он же ключ перевода.
- `js/i18n.js` — выбор языка, функция `tx()` для строк интерфейса, перевод данных урока, транскрипция латиницей для раздела «Чтение».
- `js/uz.js` — узбекский перевод интерфейса; `content/uz.json` — узбекский перевод уроков (русская строка → узбекская).
- Новая строка в коде: `node scripts/i18n-extract.cjs --wrap` оборачивает её в `tx()`, `--check` показывает, чего нет в `js/uz.js`.
- Новый урок: `node scripts/i18n-check.mjs` показывает строки уроков без перевода в `content/uz.json`.
- Видео-объяснения пока только на русском.
