# Брецель — немецкий с нуля

Мобильный сайт-курс (PWA) по немецкому языку: с нуля до A2 по программе Goethe-Zertifikat. Объяснения на русском, уроки по 5 минут, игры, интервальное повторение и тетрадь ошибок. План курса и статус блоков — в [COURSE_PLAN.md](COURSE_PLAN.md).

## Запуск

```bash
python scripts/serve.py
```

Откройте http://localhost:5173. На телефоне в той же сети сайт можно установить на главный экран (нужен HTTPS или localhost).

Сайт статический: для публикации подойдёт любой хостинг статических файлов (GitHub Pages, Netlify, Cloudflare Pages).

## Устройство

| Папка | Что внутри |
| --- | --- |
| `index.html`, `css/app.css` | Оболочка и дизайн-система (палитра кренделька, шрифт Nunito) |
| `js/` | Код без фреймворков: экраны, проигрыватель урока, упражнения, повторение, озвучка |
| `js/art.js`, `js/mascot.js` | SVG-иллюстрации, сцены, герои и маскот Брецель |
| `content/course.json` | Список тем A1–A2 |
| `content/a1/01-hallo.json` | Блок 1: слова, 12 уроков, история, тест блока |
| `audio/` | Живая озвучка (пока пусто) и `TODO.md` — список фраз для неё |
| `scripts/` | Сервер разработки, генерация иконок и озвучки |
| `sw.js`, `manifest.webmanifest` | Работа без интернета и установка на телефон |

## Озвучка

Сейчас говорит голос браузера (Web Speech API); лучше всего звучат Chrome и Edge. Живые голоса ElevenLabs:

```bash
node scripts/generate-audio.mjs --dry-run
```

Команда считает фразы и символы и пишет список в `audio/TODO.md`. Для генерации задайте переменную окружения `ELEVENLABS_API_KEY`, впишите ID голосов в `scripts/voices.json` и запустите скрипт без `--dry-run`. Ключ не сохраняется в файлах проекта.

## Новый блок

Добавьте файл темы в `content/`, отметьте тему `"ready": true` в `content/course.json`, добавьте файл в список `SHELL` в `sw.js` и увеличьте там `VERSION`.
